## What's inside

- **Navigation** — Expo Router with Drawer + bottom Tabs, auth-guarded routes, onboarding
- **UI kit** — 40+ components (buttons, inputs, sheets, modals, 17 chart types, glass surfaces) styled with Tailwind v4 via Uniwind; light/dark + 7 accent palettes
- **Data** — Zustand for app state, TanStack Query for server state, TanStack Form + Zod for forms, Axios with token refresh
- **Platform** — `expo-secure-store` persistence, i18n (EN/FR), permissions, camera, location, notifications, audio/video, OTA updates
- **Quality** — Jest + React Native Testing Library, Maestro E2E, architecture guards, strict TypeScript, ESLint, Husky hooks
- **Automation** — setup and dependency checks, scripted SDK upgrades, bundle-size reports, image optimization, local release builds, CI/E2E/weekly maintenance workflows

## System requirements

| | Minimum | Notes |
|---|---|---|
| **OS** | Windows 10/11, macOS 14+, or Linux | iOS builds need macOS |
| **Node.js** | 22.18 (LTS 22 or 24; no odd releases) | the `script/*.ts` tools run on Node's built-in TypeScript |
| **pnpm** | 10.12 | `corepack enable` picks the pinned version |
| **Android** | Android Studio · JDK 17 · SDK Platform 37 · Build-Tools 37 · NDK 27.1 | targets API 36, min API 24 · Windows: CMake 3.30+ for long paths |
| **iOS** | Xcode supported by Expo SDK 58 · CocoaPods | deployment target iOS 16.4 |
| **Hardware** | 16 GB RAM, ~25 GB free disk | a cold native build takes 15–30 min |
| Recommended | [Watchman](https://facebook.github.io/watchman/) | faster file watching |
| Optional | [Maestro](https://docs.maestro.dev) · [ffmpeg](https://ffmpeg.org) · [Docker](https://www.docker.com) | E2E tests · demo recording · containerised builds/emulator |

`pnpm run setup:check` checks all of this and tells you how to fix what's missing.

## Quick start

```bash
git clone https://github.com/MOHAMED-LAAGUILI/react-native-expo-starter-kit.git my-app
cd my-app
pnpm run setup                                   # install, env files, agent skills, machine check
npx expo run:android --device <avd-name>         # first time: build + install the dev client (emulator -list-avds)
pnpm run android:dev                             # every day after that
```

> [!IMPORTANT]
> The app runs in a **development build**, not Expo Go (it uses native modules Expo Go doesn't ship). Rebuild the dev client after adding a native package or upgrading Expo. Web needs no native build: `pnpm run web`. iOS: `npx expo run:ios`, then `pnpm run ios:dev`.

## Everyday commands

| Command | |
|---|---|
| `pnpm dev` · `pnpm run android:dev` · `pnpm run ios:dev` · `pnpm run web` | Start Metro |
| `pnpm run checks` | Lint, types, tests, i18n, doctor — runs on every commit |
| `pnpm test` · `pnpm run e2e:android` | Unit/component tests · Maestro E2E |
| `pnpm run build:local:android` | Preview APK on your machine, no EAS |
| `pnpm run build:prev:android` · `pnpm run build:prod:ios` | EAS cloud builds |
| `pnpm run deps:check` · `pnpm run upgrade:expo` | Dependency health · scripted SDK upgrade |
| `pnpm run perf:bundle` | What makes the bundle heavy, with lighter alternatives |
| `pnpm run docker:build` · `pnpm run docker:emulator` | Build and run the app in Docker |
| `pnpm run release` | Bump, tag and publish a GitHub release |

Every command is listed in [CLAUDE.md § Commands](CLAUDE.md#commands).

## Troubleshooting

- **`EBUSY` / `EPERM` during install (Windows)** — something holds `node_modules` (Metro, Gradle, your editor). Stop it and use `pnpm run install:safe`; if `node_modules` is half-written, delete it and reinstall.
- **Blank screen after launch** — another project's Metro holds port 8081. Stop it, or `npx expo start --dev-client --port 8082`.
- **Native change not in the app** — rebuild the dev client; restarting Metro only reloads JavaScript.
